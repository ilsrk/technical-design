# System design variant

Variant type for designing a system-level solution: services, deployment units, and connections between them. Adds components on top of the Solution variant base set.

## Components

| Component                  | Required |
| -------------------------- | -------- |
| `Deployment unit registry` | true     |
| `New service`              | false    |
| `Change service`           | false    |
| `New connection`           | false    |
| `Change connection`        | false    |
| `New topic`                | false    |
| `Change topic`             | false    |
| `New message`              | false    |
| `Change message`           | false    |
