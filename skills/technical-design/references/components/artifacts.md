# Artifacts

Links to external documents that must be taken into account and affect the problem being solved.

## Structure

| Field       | Description                       | Required |
| ----------- | --------------------------------- | -------- |
| Title       | Artifact title                    | true     |
| Link        | URL or path to the artifact       | true     |
| Description | Short description of the artifact | false    |
| Comments    | User comments                     | false    |

## Hard constraints

- **Never** link to designed solutions, documents, or schemas that do not yet exist in a release.
- Artifacts **MUST** contain only links to AS IS schemas and solutions. Future (TO BE) solutions are forbidden.
