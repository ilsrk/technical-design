# Alerts

Observability alerts for the designed solution.

## Structure

| Field       | Description                              | Required |
| ----------- | ---------------------------------------- | -------- |
| Name        | Alert name                               | true     |
| Condition   | Condition that triggers the alert        | true     |
| Severity    | Alert severity                           | true     |
| Description | What the alert means and how to react    | false    |
| Comments    | User comments                            | false    |
