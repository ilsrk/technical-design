# Open Questions

Unanswered questions, areas of uncertainty, difficulties, doubts, and so on.

## Structure

| Field        | Description                           | Required |
| ------------ | ------------------------------------- | -------- |
| ID           | A unique requirement identifier       | true     |
| Question     | The key question                      | true     |
| Uncertainty  | Doubts and Misgivings                 | true     |
| Comments     | User comments                         | false    |
