# User stories

List of user stories that describe the problem being solved from the user's perspective.

## Structure

| Field                | Description                                      | Required |
| -------------------- | ------------------------------------------------ | -------- |
| ID                   | A unique user story identifier                   | true     |
| Title                | Short user story title                           | true     |
| As a                 | The role or actor of the story                   | true     |
| I want               | The goal or capability the actor needs           | true     |
| So that              | The benefit or reason for the capability         | true     |
| Acceptance criteria  | Conditions that must be met for the story to be done | false |
| Comments             | User comments                                    | false    |
