# Table

Single table design: columns and attributes.

## Structure

| Field       | Description                         | Required |
| ----------- | ----------------------------------- | -------- |
| Column      | Column name                         | true     |
| Type        | Column data type                    | true     |
| Required    | Whether the column is required      | true     |
| Default     | Default value                       | false    |
| Example     | Example value                       | false    |
| Comments    | User comments                       | false    |
