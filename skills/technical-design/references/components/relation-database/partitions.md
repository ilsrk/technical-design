# Partitions

List of partitions for tables to be designed.

## Structure

| Field       | Description                              | Required |
| ----------- | ---------------------------------------- | -------- |
| Table       | Target table name                        | true     |
| Key         | Partition key                            | true     |
| Type        | Partition type (range, list, hash, etc.) | true     |
| Comments    | User comments                            | false    |
