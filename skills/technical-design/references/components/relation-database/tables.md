# Tables

Created and modified tables.

## Structure

| Field        | Description                             | Required |
| ------------ | --------------------------------------- | -------- |
| Table        | Table name                              | true     |
| Modification | Change type (create, alter, drop, etc.) | true     |
| Purpose      | Why the table is created or changed     | true     |
| Link         | Link to the detailed table design       | false    |
| Comments     | User comments                           | false    |
