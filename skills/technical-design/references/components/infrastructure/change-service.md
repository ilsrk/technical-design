# Change service

Change to an existing service.

## Structure

| Field     | Description           | Required | Type   |
| --------- | --------------------- | -------- | ------ |
| Name      | Service name          | true     | string |
| Type      | Service type          | true     | enum   |
| Changes   | List of planned changes | true   | text   |
| Comments  | User comments         | false    | text   |
