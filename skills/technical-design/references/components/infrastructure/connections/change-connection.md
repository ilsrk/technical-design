# Change connection

Change to an existing connection.

## Structure

| Field       | Description              | Required | Type   |
| ----------- | ------------------------ | -------- | ------ |
| Name        | Connection name          | true     | string |
| System      | Related system           | true     | string |
| Description | Connection description   | true     | text   |
| Changes     | List of planned changes  | true     | text   |
| Comments    | User comments            | false    | text   |
