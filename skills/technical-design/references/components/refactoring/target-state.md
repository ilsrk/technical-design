# Target state

Description of the desired (to-be) structure and behavior after the refactoring.

## Structure

| Field             | Description                                           | Required | Type |
| ----------------- | ----------------------------------------------------- | -------- | ---- |
| Structure         | Target structure, modules, layers, and dependencies   | true     | text |
| Invariants        | What must remain unchanged (contracts, API, behavior) | true     | text |
| Success criteria  | How to know the refactoring succeeded                 | true     | text |
| Comments          | User comments                                         | false    | text |
