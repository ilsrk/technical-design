# Current state

Description of the current (as-is) structure and behavior of the code or system being refactored.

## Structure

| Field      | Description                                            | Required | Type |
| ---------- | ------------------------------------------------------ | -------- | ---- |
| Scope      | Boundaries of what is being refactored                 | true     | text |
| Structure  | Current structure, modules, layers, and dependencies   | true     | text |
| Problems   | Pain points and technical debt being addressed         | true     | text |
| Comments   | User comments                                          | false    | text |
