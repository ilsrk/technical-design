# Technical design card

Root document for managing the technical design.

## Hard conventions

- The document should be concise and contain only key information.

## Sections

| Section                | Required |
| ---------------------- | -------- |
| `Basic information`    | true     |
| `Requirements`         | true     |
| `System design`        | false    |
| `Application design`   | false    |
| `Data design`          | false    |
| `Observability design` | false    |
| `Testing plan`         | true     |
| `Implementation plan`  | true     |
| `Service`              | true     |
| `Support`              | true     |
