# Solution card

The root document of the solution record. It describes the solution node, available variants, the evaluation of each variant, and the reasons for accepting or rejecting each variant.

## Sections

| Section             | Required |
| ------------------- | -------- |
| `Basic information` | true     |
| `Requirements`      | true     |
| `Solution design`   | true     |
| `Testing plan`      | false    |
| `Service`           | true     |
| `Support`           | false    |
