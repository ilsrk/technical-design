# Solution design

Design of a decision node: options, evaluations, and reasons for accepting or rejecting each option.

## Structure

| Field       | Description                                      | Required |
| ----------- | ------------------------------------------------ | -------- |
| Option ID   | Unique identifier of the option                  | true     |
| Title       | Option title                                     | true     |
| Description | Short description of the option                  | true     |
| Evaluation  | Evaluation of the option against requirements    | true     |
| Decision    | Accepted or rejected                             | true     |
| Rationale   | Reasons for accepting or rejecting the option    | true     |
| Comments    | User comments                                    | false    |
