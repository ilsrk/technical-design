# Testing plan

Test plan: a document describing how the problem being solved will be tested.

## Structure

| Field       | Description                                      | Required |
| ----------- | ------------------------------------------------ | -------- |
| ID          | Unique test case or check identifier             | true     |
| Title       | Test title                                       | true     |
| Type        | Test type (unit, integration, e2e, manual, etc.) | true     |
| Description | What is being verified and how                   | true     |
| Comments    | User comments                                    | false    |
