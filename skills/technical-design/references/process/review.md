# Review technical design

## Steps

1. Determine the review scope (an individual decision or the entire technical design).
2. Find the `Review` component in the review target.
3. Record the review in the `Review` component, authored by AI.

## Conventions

- An edit to the technical design is defined as a change to data within a section that has already been used as the basis for decisions.
- Label reviews performed by AI using the MODEL NAME + MODEL VERSION format.
