# Export technical design

## Steps

1. Determine the technical design working directory.
2. Determine the working directory in the external source.
3. Ask the user for a link to the technical design formatting style in the external source.
4. Copy the technical design to the external source.

## Hard constraints

- **Never** leave the working directory in the external repository.
- **ALWAYS** ask for permission before creating or modifying files in the external repository.

## Constraints

- Technical design formats may differ between the local and external repositories.
  - Technical design formats may differ between the local and external repositories.

## Inputs

- Link to the root directory of the technical design in the external repository.
