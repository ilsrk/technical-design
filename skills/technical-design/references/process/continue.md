# Continue technical design

## Hard constraints

- Does not write code, perform analysis, design solutions, or gather requirements.

## Steps

1. Determine the current state of the technical design based on the State Machine component in the Service section of the technical design card.
2. Display a list of the design statuses for all sections and prompt the user to continue designing an incomplete section.

## Output

- List of technical design section statuses (technical design status)
