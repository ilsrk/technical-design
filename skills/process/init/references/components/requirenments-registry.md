# Requirenments Registry

## Glossary 

**A requirements register** is a list of task requirements grouped by requirement type.

## Constraints

- A separate requirements register **MUST** be maintained for each type of requirement.

## Structure

Each requirement in the requirements register **MUST** contain the following information:
  - ID (A unique requirement identifier).
  - Title (Requirement title).
  - Description (Requirement description).

Each requirement in the requirements register **MAY** contain the following information:
  - Details (Detailed requirement description.)
  - Dependencies (References to the parent requirements)
  - Comments (User comments)
