# About

Agent skill for a component-based technical design. It creates a design directory and a root document, then walks requirements, solution cards, review, and validation before implementation. The entry point is [skills/technical-design/SKILL.md](skills/technical-design/SKILL.md).

| Process | When it runs |
| --- | --- |
| Init | Start a technical design |
| Continue | Resume an existing design |
| Edit | Change a design and its related components |
| Review | Check that solutions meet the requirements |
| Validate | Check completeness, diagrams, and wording |
| Apply | Implement the selected plan |

# Quick Start

```
npm install -g @ilsrk/technical-design@latest

```
